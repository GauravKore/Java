## 📌 About This Repository

This repository contains my **complete Java Core learning journey**, including concepts, implementations, practice programs, and interview-oriented examples.

The primary goal is to build a strong foundation in Java before moving into **Spring, Spring Boot, Backend Development, REST APIs, Hibernate/JPA, and System Design**.

Instead of only learning theoretical concepts, I focus on understanding:

- How Java works internally
- Why a particular concept exists
- How it is implemented
- Where it is used in real applications
- Common interview questions and problems
- Writing clean and maintainable Java code
